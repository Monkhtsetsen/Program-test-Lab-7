# BUG-07: API хоосон title-тэй номын хүсэлтийг амжилттай боловсруулж байна

**Орчин:** Уншлагын жагсаалт v2.0, Firefox болон Linux терминал, Ubuntu Linux, 2026-10-21

**Урьдчилсан нөхцөл:** `node app.js` командыг ажиллуулж API-г асаасан.

## Дахин гаргах алхам

1. Терминал нээнэ.
2. Дараах хүсэлтийг API руу илгээнэ.

   ```bash
   curl -i -X POST "http://localhost:3000/api/books" \
     -H "Content-Type: application/json" \
     --data-raw '{"title":"","author":"Munkhtstesen","year":2000}'
   ```

3. HTTP статус болон хариуны биеийг шалгана.

**Хүлээгдэж байсан:** Хоосон `title` хүчинтэй биш тул API `400 Bad Request` эсвэл `422 Unprocessable Entity` хариу буцааж, шинэ номын бүртгэл үүсгэхгүй.

**Бодит үр дүн:** API `201 Created` статус буцааж, `{"result":"OK","id":15}` гэсэн хариу өгсөн. Энэ нь хоосон нэртэй хүсэлтийг амжилттай хүлээн авч, шинэ бүртгэл үүсгэснийг харуулж байна.

**Ноцтой байдал:** Major — Сервер талын өгөгдөл баталгаажуулалт хангалтгүй тул хүчинтэй бус мэдээлэл API-аар бүртгэгдэх боломжтой.

**Хавсралт:** `evidence/T10_api_empty_title.txt` — `curl -i`-ийн гаралт. Файлыг шалгаж, бүтэн HTTP статус болон хариу агуулж байгааг баталгаажуулна.

**Олдсон аялал:** Saboteur — API-level testing
