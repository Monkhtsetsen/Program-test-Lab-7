## bug-06: API хоосон гарчигтай номыг 201 Created-ээр хүлээн авч байна

- **Түвшин (Severity):** High
- **Төрөл:** API / Серверийн талын оролтын шалгалт
- **Илрүүлсэн тест:** T10 (16:33–16:40)
- **Endpoint:** `POST http://localhost:3000/api/books`
- **Урьдчилсан нөхцөл:** Апп http://localhost:3000 дээр ажиллаж байна.

**Алхмууд:**

1. `POST http://localhost:3000/api/books` руу доорх бие (body)-тэй хүсэлт илгээнэ.
2. Хариуны статус код болон биеийг шалгана.

**Хүсэлтийн бие (Request body):**

```json
{
  "title": "",
  "author": "Munkhtstesen",
  "year": 2000
}
```

**Хүлээгдсэн үр дүн:** API нь 400 Bad Request эсвэл 422 Unprocessable Entity буцааж, ном үүсгэхгүй.

**Бодит үр дүн:** API нь 201 Created статус буцааж, дараах хариугаар шинэ бүртгэл үүсгэсэн:

```json
{
  "result": "OK",
  "id": 11
}
```

**Нөлөө:**

- Сервер талд `title`-ийн шалгалт байхгүй тул UI-г тойрч шууд API-аар хоосон гарчигтай бүртгэл үүсгэх боломжтой.
- Өгөгдлийн сангийн бүрэн бүтэн байдал алдагдана (гарчиггүй ном).
- UI талд мөн ижил согог илэрсэн (bug-01) тул UI болон сервер хоёулаа шалгалтгүй байна. bug-01-ийн үндсэн шалтгаан серверийн талд байж магадгүй.

**Нотолгоо:**

- `evidence/T10_api_empty_title.txt`
- `evidence/T10_api_empty_title.png`

**Санал болгох засвар:**

- Серверийн талд `title` хоосон биш (trim хийсний дараа) байхыг шалгаж, алдаа гарвал 400/422 буцаах.
- Мөн `author`, `year` талбарт ижил төрлийн шалгалт нэмэх.

**Дахин тестлэх нөхцөл:** Зассаны дараа T10-ыг давтаж, 400/422 статус буцаж байгааг, мөн шинэ бүртгэл үүсээгүйг (нийт номын тоо өөрчлөгдөөгүйг) шалгана. Нэмэлтээр зөвхөн хоосон зай (`"   "`), `title` талбарыг огт илгээхгүй (missing), `null` утгатай тохиолдлуудыг шалгана.
