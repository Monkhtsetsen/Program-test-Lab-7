# BUG-02: Ном нэмэх үед зохиогчийн нэргүй бүртгэл үүсэж байна

**Орчин:** Уншлагын жагсаалт v2.0, Firefox, Ubuntu Linux, 2026-10-21

**Урьдчилсан нөхцөл:** `node app.js` командыг ажиллуулж аппыг шинээр асаасан. Эхний 3 ном харагдаж байна.

## Дахин гаргах алхам

1. `http://localhost:3000` хаягаар апп руу орно.
2. Номын нэрийн талбарт тестийн нэр оруулна.
3. Зохиогчийн нэрийн талбарыг хоосон үлдээнэ.
4. Он оруулаад нэмэх товчийг дарна.

**Хүлээгдэж байсан:** Зохиогчийн нэр заавал бөглөх талбар тул ном нэмэгдэхгүй бөгөөд алдааны мэдээлэл гарна.

**Бодит үр дүн:** Апп ном нэмэгдсэн тухай мэдээлэл харуулж, зохиогчийн нэргүй номыг хүснэгтэд нэмсэн. Нийт номын тоолуур 6-аас 7 болсон.

**Ноцтой байдал:** Major — Зохиогчийн мэдээлэл дутуу бүртгэгдэж, номын жагсаалтын бүрэн бүтэн байдал алдагдана.
