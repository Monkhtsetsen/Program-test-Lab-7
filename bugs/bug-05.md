# BUG-05: Давхардсан ном нэмэх тестийн үр дүн баталгаажаагүй

**Орчин:** Уншлагын жагсаалт v2.0, Firefox, Ubuntu Linux, 2026-10-21

**Урьдчилсан нөхцөл:** `node app.js` командыг ажиллуулж аппыг асаасан.

## Дахин гаргах алхам

1. `http://localhost:3000` хаягаар апп руу орно.
2. Номын нэр, зохиогч болон оныг оруулна.
3. Нэмэх товчийг хоёр удаа дарж, хүсэлтийг давхар гүйцэтгэнэ.
4. Хүснэгтэд нэмэгдсэн мөрийн тоо болон нийт номын тоолуурыг шалгана.

**Хүлээгдэж байсан:** Давхардсан ном нэмэхийг хориглох шаардлага байгаа тохиолдолд ижил номыг хоёр удаа бүртгэхгүй байх ёстой.

**Бодит үр дүн:** Нэмэх үйлдлийг санамсаргүйгээр хоёр удаа гүйцэтгэсэн тул хүснэгтэд хоёр шинэ мөр нэмэгдэж, нийт номын тоолуур 2-оор өссөн. Давхардсан номыг систем зориудаар зөвшөөрсөн эсэх, эсвэл хоёр хүсэлт давхар илгээгдсэнээс ийм үр дүн гарсан эсэхийг тухайн оролдлогоор баталгаажуулж чадаагүй.

**Ноцтой байдал:** Одоогоор тогтоогоогүй — дахин тест хийж, давхардлыг хориглох шаардлага болон бодит зан төлөвийг баталгаажуулах хэрэгтэй.

**Хавсралт:** Баталгаажсан нотолгоо байхгүй.

**Олдсон аялал:** Supermodel — GUI exploration
