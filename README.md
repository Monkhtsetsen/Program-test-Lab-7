## Хэсэг E: Дүгнэлт

Энэ session-ээр нийт 11 тестийн оролдлого бүртгэгдсэнээс 4 нь PASS, 6 нь FAIL, 1 нь баталгаагүй үр дүнтэй байв. PASS үр дүнтэй тестүүдэд хүчинтэй мэдээллээр ном нэмэх (T01), ном хайх (T07), хүчинтэй мэдээлэлтэй API хүсэлт боловсруулах (T08), ном устгасны дараа хүснэгтийн мөр болон нийт номын тоолуур зөв буурах (T09) үйлдлүүд багтсан. FAIL үр дүнтэй тестүүдээр хоосон гарчигтай ном нэмэгдэх (BUG-01), хоосон зохиогчтой ном нэмэгдэх (BUG-02), зөвшөөрөгдсөн хязгаараас гадуурх онтой ном нэмэгдэх (BUG-03, BUG-04), давхардсан ном нэмэгдэх (BUG-06), мөн API хоосон гарчигтай хүсэлтийг хүлээн авах (BUG-07) зэрэг согог илэрсэн. T06 тестийн эхний оролдлогоор нэмэх үйлдлийг санамсаргүй хоёр удаа гүйцэтгэсэн тул үр дүнг баталгаажуулах боломжгүй байсан бөгөөд BUG-05-ыг батлагдсан согогийн тоонд оруулаагүй. Couch Potato аялал нь хоосон болон буруу оролтын боловсруулалтыг шалгахад үр дүнтэй байсан бол Saboteur аяллаар API-ийн өгөгдөл баталгаажуулалтын согогийг илрүүлсэн. Fed-Ex аяллаар ном устгасны дараа хүснэгтийн мөрийн тоо болон нийт номын тоолуур хоорондоо нийцэж байгааг баталгаажуулсан. Урт текст, зөвхөн зайнаас бүрдсэн утга, хайлтын том жижиг үсгийн ялгаа болон буруу бүтэцтэй JSON-ийг шалгаж амжаагүй тул дараагийн session-д эдгээрийг турших шаардлагатай. Лаборатори №1-ийн Playwright автомат тестээр хоосон талбар, буруу он, давхардсан ном болон устгалын дараах тоолуурын өөрчлөлтийг тусгай assertion ашиглан шалгаж болно. BUG-07-г API түвшний автомат тестээр илрүүлэх боломжтой боловч зөвхөн UI-г шалгадаг тестээр илрүүлэх нь баталгаатай биш. Харин устгах товчны өнгө, хүснэгтийн байрлал болон урт текстийн улмаас үүсэх харагдах байдлын асуудлыг хүний нүдээр шалгах эсвэл visual regression тест ашиглан илрүүлж болно.

## Хэсэг F: AI ашигласан туршилтын дүгнэлт

Би ChatGPT-д лабораторийн ажлын спецификацыг өгч, exploratory testing-ийн нэмэлт charter-ууд санал болгохыг хүссэн. AI миний анхны charter-аас гадна статистикийн нийцэл (CH-04), тусгай тэмдэгт болон XSS-ийн боловсруулалт (CH-05), API-ийн алдаа боловсруулах чадвар (CH-06), хэрэглэгчид харагдах мэдэгдлийн нийцэл (CH-07) зэрэг чиглэлүүдийг санал болгосон. Эдгээрээс би өөрийн session-ээр тусгайлан шалгаж амжаагүй XSS, буруу бүтэцтэй JSON, байхгүй ID-тай устгах хүсэлт болон хамгийн шинэ оны статистикийг цаашид шалгах хэрэгтэй гэж үзсэн. Мөн өөрийн T10 тестийн түүхий тэмдэглэл болон API-ийн бодит хариуг ChatGPT-д өгч BUG-07 тайлан бичүүлсэн. AI-ийн тайлан бодит HTTP статус `201 Created`, хариуны `{"result":"OK","id":15}` болон тестийн цаг зэрэг миний тэмдэглэлд байсан мэдээллийг зөв ашигласан. Гэхдээ зөвхөн хоосон гарчиг туршсан байхад зөвхөн зайтай гарчиг, гарчгийн талбар байхгүй хүсэлт зэрэг нэмэлт нөхцөлийг retest шалгуурт оруулсан тул эдгээрийг бодитоор туршсан үр дүн гэж үзэж болохгүй. Энэ туршилтаас AI нь тестийн шинэ санаа гаргах, тайланг бүтэцтэй бичихэд хэрэгтэй боловч нэмэлтээр санал болгосон алхам, үр дүнг өөрөө баталгаажуулах шаардлагатайг ойлгосон.
