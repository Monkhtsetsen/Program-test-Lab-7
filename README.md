## Зорилго

Уншлагын жагсаалт веб апп дээр Session-Based Test Management (SBTM) аргыг ашиглан exploratory тест хийх, ажиглалтаа тэмдэглэх, илэрсэн согогийг баримтжуулах.

## Файлууд

- **charter.md** — тестийн төлөвлөгөө

- **session-report.md** — 60 минутын session-ийн тэмдэглэл

- **bugs/** — согогийн тайлангууд

- **evidence/** — API тестийн нотолгоо

- **screenshots/** — UI согогийн скриншотууд
